Xem model SketchUp trên điện thoại

Cách làm

  1. SketchUp: Extensions › PoLi › Xuất xem điện thoại → ra file .glb
  2. Tải file lên Google Drive → Chia sẻ → Bất kỳ ai có đường liên kết → Sao chép đường liên kết
  3. Dán link vào ô trên → Xem model → bấm Gửi link để gửi qua Zalo
